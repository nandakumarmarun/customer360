MODAL STYLING OVERRIDE & DYNAMIC NAVIGATION FIXES FOR UI-RENDERER.JS
=============================================================

Below are the changes applied inside `ui-renderer.js` to fix two issues in the embedded Lenovo Vantage container widget:
1. Fullscreen 'No Data Present' overlay modal styles breaking and displaying as ellipsis (...).
2. Navigation failure when clicking the 'Go to Customer Search' button.

FILE: ui-renderer.js


1. STYLING FIX:
--------------
Inline styles for the modal overlay/card elements are updated with `!important` attributes and explicit text-wrapping rules (`white-space: normal !important; overflow: visible !important; text-overflow: clip !important;`) to prevent host stylesheet bleed.

2. DYNAMIC NAVIGATION & CONFIG MATCH:
------------------------------------
- Defined `const searchUrl = (window.API_CONFIG && window.API_CONFIG.CUSTOMER_SEARCH_URL) || 'customer-search/customer-search.html';` in `showNoDataAlert`.
- Replaced the hardcoded href/onclick handler URL with `${searchUrl}` so the modal button dynamically reads from `CUSTOMER_SEARCH_URL` in `config.js`.
- Configured `triggerSearchTransition` to navigate directly using `window.location.href = targetUrl;` because dynamically loading preloader scripts is blocked/fails in host Vantage widget environments.
