How to Apply the Lottie Loader to Customer360

To migrate from the standard CSS loading spinner to your preferred Lottie animation, follow these quick implementation steps:

  • 1️⃣

    Include the Lottie Library

    Ensure that the lottie-web library script is added in the head section of your main index.html:

    <script src="https://cdnjs.cloudflare.com/ajax/libs/lottie-web/5.12.2/lottie.min.js"></script>
  • 2️⃣

    Update the JavaScript Render Code

    Modify the showLoader method in ui-renderer.js to render a Lottie container instead of the plain <div class="card-spinner"></div> element, and initialize the player dynamically.

  • 3️⃣

    Select a Fallback Mechanism

    Always maintain a clean SVG or CSS fallback (included automatically in the snippets below) in case of network timeouts or blocked scripts. This guarantees a bulletproof user experience.
